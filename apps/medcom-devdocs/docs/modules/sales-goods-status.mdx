Mục lục lấy từ thanh điều hướng `/help`; Các API dưới đây được đối chiếu bằng đúng mã phân hệ.

:::info Chưa có API · Chưa xác minh (UNKNOWN)

Chưa có route module `/api/erp/sales-goods-status` trong bản OpenAPI được lưu. Chưa xác nhận được trường dữ liệu, yêu cầu/kết quả hoặc quy trình tương ứng. Không tự gán sang API có tên tương tự.

:::

## Việc cần xác nhận

Cần xác nhận mã phân hệ, đường dẫn, quyền, trường dữ liệu và quy trình nghiệp vụ trước khi tích hợp. Xem trang Tra cứu API để biết các API hiện có.
