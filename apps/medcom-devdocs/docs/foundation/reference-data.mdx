Bảng này mô tả ánh xạ kỹ thuật để API bổ sung tên hiển thị. Đây không phải danh sách bản ghi hoặc giá trị lựa chọn thực tế; cần tải các giá trị qua API được cấp quyền.

**Nguồn tham chiếu:** `inventories/backend/20261011/api-reference-bindings.json`. Đây là bản mô tả kỹ thuật được lưu từ nguồn; cần đối chiếu môi trường triển khai khi tích hợp. Thuộc tính writable không thay thế quyền ghi của tài khoản.

Bảng SQL: `CF_ItemTbl` · trường mã `ItemID` · trường tên `ItemName`.

Tên trường nguồn tương ứng: `ItemID`. Trường bổ sung: `ItemCode`, `Unit`.

| Cột | Kiểu SQL | Cho phép null |
|---|---|---|
| `ItemID` | `nvarchar(50)` | Không |
| `ItemName` | `nvarchar(max)` | Có |
| `ItemCode` | `nvarchar(100)` | Có |
