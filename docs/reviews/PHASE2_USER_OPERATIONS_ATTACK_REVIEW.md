# Phase 2 user and operations attack review

Review date: 2026-10-01 (Asia/Bangkok). Owner: Lead with UX, ERP, DB, QA and operations lanes.

**Disposition: tabletop review only; contracts need implementation proof and evidence blockers remain open.** These attacks were reasoned about against documents. No production app was started, database was queried or changed, live attack was executed, or CI pass was claimed. Finding a documented rule does not establish that the application implements it.

The 52 stable `UX-OPS-*` cases below supplement the security and transaction reviews. They cover ordinary users, accounting, warehouse, purchasing management, IT/admin, mobile, keyboard/accessibility, support and release/scheduled-work operations. They must become acceptance cases in their existing owner issues, rather than independent duplicate implementations.
