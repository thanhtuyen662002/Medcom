## Yêu cầu chi tiết

### `model.ts`: view model mà controller (T-004/T-006) sẽ cung cấp

```ts
export interface DetailRow { lineId: string; fields: Record<string, unknown> }
export interface DetailPage { rows: readonly DetailRow[]; hasMore: boolean }
export interface DetailAction {
  id: string; label: string;
  placement: "primary" | "menu";        // footer hay menu "Thao tác khác"
  tone?: "default" | "outline" | "danger";
  visible: boolean; enabled: boolean; reason?: string; // reason đã là câu tiếng Việt
  busy?: boolean;
}
export interface DetailFeedback { type: "success" | "warning" | "error"; message: string }
export interface DocumentDetailModel {
  documentId: string | null;
  header: Record<string, unknown>;
  lines: DetailPage; history?: DetailPage; sections?: Record<string, DetailPage>;
  status: { label: string | null; locked: boolean | null };
  loading: boolean; error: string | null;
  editing: boolean; dirty: boolean; busy: boolean;
  draft: Record<string, string>;
  feedback: DetailFeedback | null;
  pending?: { title: string; body: string; actions: readonly DetailAction[] };
  actions: readonly DetailAction[];
}
export interface DocumentDetailHandlers {
  onAction(id: string): void;
  onFieldChange(key: string, value: string): void;
  onLoadMore(section: "lines" | "history" | string): void;
  onRetry(): void;
}
```

Được chỉnh tên/kiểu cho hợp lý nếu có lý do, nhưng phải giữ nguyên ý: layout **không** gọi API và không biết module.

### Component

- `DocumentDetailDialog`: shell dùng `RecordDialog` (`components/erp/record-dialog.tsx`), portal ra `document.body` sau khi mount, giữ y nguyên cách làm và chuỗi class của `components/erp/erp-detail-sheet.tsx:11-30` (đọc comment ở dòng 15-17 về transform animation). Props: `open`, `presentationAllowed`, `title`, `documentNumber`, `closeLabel`, `onRequestClose`, `children`. Không có prop nào nhắc tới bán hàng.
  - Lưu ý lint: `erp-detail-sheet.tsx:12` đang dính lỗi `react-hooks/set-state-in-effect` (baseline). Bản mới **không được** lặp lỗi này: dùng `useSyncExternalStore` hoặc cách khác không gọi setState đồng bộ trong effect.
- `DocumentDetailView({ config, model, handlers, module, slots? })`:
  - Thứ tự: status (portal qua `RecordDetailStatus`) → notices (feedback, pending) → notice theo `config.notice[module]` → các `groups` → tabs → slots → action bar (qua `RecordActionBar`).
  - `slots?: Partial<Record<DetailSlotId, ReactNode>>`: chỉ render slot có trong `config.slots`. Slot `lines-editor` thay tabs khi `model.editing`.
  - Trạng thái `loading` / `error` hiện như `sales-order-form.tsx:288-290` (có nút "Thử lại" → `onRetry`).
- `DocumentFieldGroup`: card theo `RecordSection` nội bộ của `sales-order-form.tsx:39-45`, lưới `dl` theo `requestStyles.values`. Giá trị qua `formatDetailValue` (T-001). Ưu tiên `displayKey`, rồi `secondaryKey` hiện dòng nhỏ. `format: "url"` hiện link "Mở tài liệu" khi `isHttpUrl`. `hideWhenEmpty` mặc định true. `subgroups` có tiêu đề `h4` như "Người phụ trách". Nếu mọi trường rỗng mà có `emptyStrip`, hiện dải gọn như `sales-order-form.tsx:353-356`.
  - Chế độ sửa (`model.editing` và field có `edit`): `date` → `RequestInput type="date"`, `text` → `RequestInput`, `textarea` → `RequestTextarea`, `money` → `MoneyInput` (`components/erp/money-input.tsx`), `lookup` → `LookupField` (`components/untitledui/lookup-field.tsx`) với `lookupId`, `required`, `multiple`. Giá trị lấy từ `model.draft[key]`, thay đổi gọi `onFieldChange`. Trường không có `edit` vẫn hiện dạng xem khi đang sửa.
- `DocumentDetailTabs`: tổng quát hóa `SalesOrderDetailTabs`. Tab dòng dùng `config.lines.columns` (cột `role:"primary"` là ô tên hàng 2 dòng; `role:"total"` đậm màu brand) và `expandGroups` cho phần mở rộng. Tab lịch sử chỉ có khi `config.history`. Mỗi `config.sections[key]` thêm một tab. Giữ đầy đủ ARIA tablist, phím mũi tên/Home/End, bảng desktop và thẻ mobile, nút "Tải thêm…" → `onLoadMore`. Ô dòng dùng `formatDetailValue` theo `format` của cột (không tự gọi `isMoneyField`).
- `DocumentActionBar`: nút `placement:"primary"` ở footer (`RequestButton`), các nút `placement:"menu"` gom vào nút "Thao tác khác" (icon `MoreHorizontal`) mở `UntitledBottomSheet` như `sales-order-form.tsx:400-410`. Nút disabled hiện `reason` qua `title`. `tone:"danger"` màu đỏ.

### Test `tests/document-detail-view.test.mjs`

Theo kiểu `tests/shared-screen-ui.test.mjs` (esbuild bundle + `renderToStaticMarkup`). Dùng **config giả** viết ngay trong file test (không import `modules/**`). Tối thiểu:

5. Chế độ sửa: field `edit.input:"date"` render `input type="date"` với giá trị draft; field không có `edit` vẫn là `dd`.
6. Tabs: số đếm dòng/lịch sử đúng; không có `config.history` thì không có tab lịch sử; section phụ thành tab.
7. Action bar: nút primary hiện label; nút menu không hiện ở footer; nút `visible:false` không render.
