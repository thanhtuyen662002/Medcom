## Yêu cầu chi tiết

### `types.ts`

Export đúng các kiểu trong thiết kế mục 2.1, gồm `FieldFormat`, `DetailFieldConfig`, `DetailGroupConfig`, `LineColumnConfig`, `DocumentDetailConfig`, và thêm:

- Chỉ chứa type (không có code chạy), trừ `DETAIL_SLOT_IDS` (`as const` array) nếu cần cho kiểm tra.
- Mọi field `readonly` ở mức mảng (`readonly DetailFieldConfig[]`…) để config khai báo bằng `as const satisfies` được.
- JSDoc ngắn bằng tiếng Việt hoặc tiếng Anh cho từng field, khớp với thiết kế.

### `format.ts`

Export:

```ts
export const EMPTY_VALUE = "—";
export function formatBoolean(value: unknown): string;          // true/1/"1"/"true" → "Có"; false/0/"0"/"false" → "Không"; còn lại → "—"
export function formatDate(value: unknown): string;             // "2026-10-23..." → "23/10/2026"
export function formatDateTime(value: unknown): string;         // giờ 00:00(:00) → chỉ ngày; ngược lại "dd/MM/yyyy HH:mm"
export function formatNumber(value: unknown): string;           // vi-VN; không phải số → trả nguyên chuỗi
export function formatDetailValue(value: unknown, format?: FieldFormat, options?: { statusName?: unknown }): string;
export function isEmptyDetailValue(value: unknown): boolean;    // null, undefined, "" , chuỗi chỉ có khoảng trắng
export function isHttpUrl(value: unknown): boolean;             // /^https?:\/\//i sau trim
```

- `formatDetailValue`: rỗng → `EMPTY_VALUE`; `money` → `formatMoney` từ `../money`; `status` → `documentStatusLabel(statusId, statusName)` từ `../document-status`; `boolean`/`date`/`datetime`/`number` như trên; `text`/`multiline`/`url`/`reference`/không có format → `String(value)` (object/array → `EMPTY_VALUE`, không bao giờ in `[object Object]`).
- Logic ngày và số **sao chép hành vi** của `formatVietnamDate` / `formatVietnamNumber` trong `components/untitledui/tab-erp-screen.tsx:254-271` (không sửa file đó; T-006 sẽ xóa bản cũ). Khác biệt duy nhất được phép: giá trị rỗng trả `EMPTY_VALUE` thay vì `""`.
- Không dùng `Number()` cho tiền (đã do `formatMoney` lo).

### Test `tests/document-detail-format.test.mjs`

Theo đúng kiểu `tests/money.test.mjs` (bundle bằng esbuild vào `.test-runtime/document-detail-format`, alias `@`). Tối thiểu các ca:

1. Boolean: `true, 1, "1", "true", "True"` → "Có"; `false, 0, "0", "false"` → "Không"; `null, undefined, "", "abc"` → "—".
2. Ngày: `"2026-10-23T00:00:00"` → `23/10/2026`; `"2026-10-23T14:05:00"` qua `formatDateTime` → `23/10/2026 14:05`; chuỗi không phải ngày → trả nguyên.
3. Số: `"1234567.5"` → `1.234.567,5`; `"abc"` → `"abc"`.
4. `formatDetailValue(…, "money")` khớp `formatMoney` với `"123456789012345678.9012"`.
5. `formatDetailValue(false, "boolean") === "Không"`; `formatDetailValue({a:1}) === "—"`; `formatDetailValue("", "text") === "—"`.
6. `formatDetailValue(…, "status", {statusName})` khớp `documentStatusLabel`.
7. `isHttpUrl(" https://x ")` true, `"ftp://x"` false.
