Medcom — Kiểm tra API

Đăng nhập bằng tài khoản ERP để thử API theo quyền và chi nhánh của bạn. Các lệnh tạo, sửa, xóa và gửi có thể thay đổi dữ liệu đang kết nối.

Chưa đăng nhập.

Chọn API → Try it out → nhập dữ liệu → Execute. Token và phạm vi dữ liệu được gửi tự động. Với lệnh ghi, giữ nguyên mã yêu cầu khi kiểm tra lại kết quả; trang này không tự gửi lại lệnh.
