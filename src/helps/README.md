# Medcom ERP help center

Static HTML, CSS and JavaScript documentation for the existing Windows ERP.
User guides and technical references share the approved white/blue Medcom header
and navigation, with a procedural article layout.

Content reconciliation against the seven owner-provided Word guides and the
current read-only MedData configuration is in progress on this branch.

Only sanitized instructional content belongs here. Raw Word files, customer
screenshots, transaction rows, credentials and private SQL bodies are excluded.
